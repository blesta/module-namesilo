# Blesta/Dynadot

Blesta Dynadot module

## Description

This module interfaces with Dynadot's domain API to allow domain registrations, transfers and renewals through Blesta.

## Install the Module

1. Upload `dynadot` to the `/components/modules/` directory of your Blesta installation.
2. Log in to your Blesta admin interface.
3. Go to **Settings > Modules**.
4. Click the **Available** tab.
5. Click **Install** for the Dynadot module.

## Usage

Enable the Dynadot module and go to Manage to enter your Dynadot API key. Enable or disable sandbox mode to enable or disable module testing.

**[Get your Dynadot account here](https://www.dynadot.com/)**
